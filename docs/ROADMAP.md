# PennyPilot Roadmap

## Version 1.0: Core Platform

- Authentication
- Accounts and transactions
- Transfers and refunds
- Budgets and savings goals
- Recurring payments
- Analytics and reports
- PostgreSQL persistence
- Vercel, Render, and Neon deployment

## Version 1.1: Intelligent Assistance

- Read-only Groq AI Coach
- Lifetime financial aggregates
- Follow-up conversation context
- Markdown tables
- Smart transaction-entry suggestions

## Version 1.2: Reconciliation

- CSV statement import
- Universal column mapping
- Preview before commit
- Duplicate detection
- Import batches and undo
- Category and merchant suggestions
- Closing-balance reconciliation

## Version 2.0: Production Hardening

- Email verification
- Password recovery
- Multi-factor authentication
- Structured audit-event log
- Private object storage for receipts
- Distributed rate limiting
- Automated backup restoration tests
- Structured logs and correlation IDs
- Error tracking and performance monitoring
- Accessibility audit
- Load and security testing

## Future Regulated Integration

- Account Aggregator sandbox demonstration
- Eligible FIU partnership assessment
- Consent lifecycle and revocation
- Security and compliance review
- Production reconciliation across supported banks
